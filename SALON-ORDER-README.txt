BeautyFlow — подредба на салон и специалност (01.10.2026)

Разархивирай в BeautyFlow със замяна. Само изброените файлове са включени.
Подредба след информацията за салона: записване, услуги, екип, галерия.
Екип: светли карти с тъмни имена и специалности.
Специалност: ръчно текстово поле до 90 символа в Моят профил и Покани специалист. Запазването/поканата приемат свободния текст. Старите стойности не се променят автоматично.
Механизмите за записване, изпращане на код, потвърждение, услуги, галерия и изчакване не са променяни. Съществуващото скриване на секциите при активен процес на записване се запазва.
Двата deep теста са адаптирани само да попълват новото поле, вместо да избират от падащ списък. Онлайн тестовете от предишния пакет не са включени и не се заменят.
Не се изискват SQL или npm install.
Проверки тук: npm run build и TypeScript успешно; сравнение на преместените JSX блокове — идентични. Реален тест с админ/имейл и мобилен браузър не е изпълняван тук.
След замяната: npm run build. Публичната онлайн версия ще се промени след commit/push и deployment Ready.
