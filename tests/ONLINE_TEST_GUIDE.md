# Онлайн release тест

Пакетът променя само tests/booking-full.spec.ts, tests/waitlist-full.spec.ts и добавя tests/online-email.ts. Не променя сайта, DNS, имейл маршрути или базата.

В .env.test.local добави TEST_CUSTOMER_EMAIL=реална_твоя_поща. Остави TEST_SALON_SLUG да сочи към твоя тестов салон с услуги, работен график и активен достъп. Не използвай клиентски салон.

В CMD:

```cmd
set TEST_BASE_URL=https://www.beautyflow.bg
npm run test:release:headed
```

При теста booking-full отвори пощата си и въведи получения код в полето в тестовия браузър. НЕ натискай бутона за потвърждение: тестът го натиска след като види 6 цифри. Има 3 минути за въвеждане.

Тестът изпраща истински писма, създава тестово записване и изчакващ, проверява админ календара и изтрива създадените часове при успешно завършване. Ако тестът прекъсне след създаване, провери за останали записи с имена E2E BeautyFlow / E2E Waitlist и премахни само тях.

Waitlist тестът вече изисква emailSent=true след назначаване на час. Това потвърждава приемането от изпращащата услуга; доставката във входящата поща се проверява отделно. booking-full с ръчно въведен код потвърждава и получаването на писмото с кода. Няма автоматичен достъп до пощата.

Тестовете deep-media/deep-team-booking/az не са включени в тази промяна и не са пригодени за production. Release тестът не проверява абсолютно всички функции или скоростта на мобилен телефон.

Локалният E2E режим се запазва. За локално изпълнение използвай set TEST_BASE_URL=http://127.0.0.1:3000 и същата команда.

Не се изискват npm install, SQL, build или deployment за този пакет. Тестовете се изпълняват от компютъра ти срещу вече качения сайт.
